# Azure SRE Agent Runbooks

These assets support the fallback path for the controlled Azure SRE Agent incident.

- `challenge-04-incident-packet.md` gives participants a simulated Grubify production signal.
- `challenge-04-triage-template.md` captures the operational response.
- `generated/` may be created by local simulation scripts and is intentionally ignored by Git.

Prefer live Azure SRE Agent evidence. Otherwise, preserve the same sequence: Azure signal, telemetry evidence, agent transcript, source-code lead, remediation work with evidence and human approval, recovery proof, and one follow-up improvement.
