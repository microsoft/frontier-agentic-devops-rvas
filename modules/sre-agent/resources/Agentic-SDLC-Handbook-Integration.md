## Source Caveats

- The Agentic SDLC Handbook is a living pre-release document by Daniel Meppiel and is licensed [CC BY-NC-ND 4.0](https://creativecommons.org/licenses/by-nc-nd/4.0/). Attribute it, summarize it, and do not adapt or reproduce long passages.
- GitHub Agentic Workflows and Peli's Agent Factory describe early workflow technology that continues to change. Use them as sourced examples. Do not promise that every customer tenant can run each workflow unchanged.
- Keep live-product limits visible. Preview access, repository permissions, model or provider setup, GitHub Actions policy, secrets, and tenant controls can change the hands-on path.
